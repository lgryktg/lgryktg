# 用户管理与使用分析说明

## 入口

- 用户管理：http://127.0.0.1:4318/#users
- 使用分析：http://127.0.0.1:4318/#usage
- 运营总览：http://127.0.0.1:4318/#overview

你是唯一管理员，普通业务用户不进入此后台；业务系统原有的数据隔离继续保留。

## 已确认的范围

完整 IP；登录历史保留 90 天。只查看用户资料、登录记录、用量和趋势，不展示剧本正文、提示词、图片或视频内容。

用户资料包含用户 ID、注册邮箱、账号状态、注册时间、注册 IP、最近成功登录 IP 与时间、最近生成调用时间。详情另显示当前剩余额度。

IP 从本次启用后开始记录，既有用户未记录过的字段保持空值。正常注册与成功登录会更新账号资料；能关联到已有账号的失败登录会保存失败记录，但不更新最近成功登录 IP。不保存输入的密码、验证码、会话令牌或请求正文。未识别到的账号不会被伪装成已注册用户。

登录明细存于业务系统 accounts.sqlite 的 accountLogins 表；账号 IP 元信息存于 accountAccess 表。明细查询仅限最近 90 天，业务服务启动及每小时清理过期明细。注册与最近成功登录 IP 属于账号资料，持续保留，不随登录明细一起清除。

客户端 IP 使用 Express 的 req.ip，沿用原系统只信任环回代理的设置，不直接读取未经校验的 X-Forwarded-For。未来上线若使用容器、负载均衡或非本机代理，需要按实际拓扑配置可信代理，不能直接信任任意转发头。

## 使用统计口径

1. 注册用户列表包含所有 users 表账号，可分页查看；停用账号也保留。不将本机 administrator 账号当作普通注册用户。
2. 活跃用户是当前周期中至少有一次生成调用的注册用户，不等同登录用户数。
3. 文本、图片、视频、音频的使用占比按请求次数计算，包含已完成、失败及待核对调用；图片张数和视频秒数单独展示。
4. 用户的使用侧重点取调用次数最多的类型，并列时标记多类型使用；没有调用时标记暂无调用。
5. Token 统计来自源系统文本模型账本。已结算调用的总量采用账本 units，输入、输出、缓存读取和缓存写入分别采用原始字段；没有上报的分项显示未知。
6. pending / unknown 为待确认状态，其 units 不当作已确认消耗。存在已上报部分时可展示已知值并加 +，完全未上报时显示未知。图片和视频按已结算张数、秒数统计。
7. 使用周期按调用创建时间滚动筛选，展示和日趋势按上海时间聚合，首尾可能为非完整日。全部时间的累计指标覆盖全部历史，趋势只显示最近 30 天。
8. 用户画像、趋势和模型统计直接聚合完整账本，不使用最近 10000 条快照估算。模型分布最多 30 组，Token 排行最多前 5 位，调用明细展示最近 50 条。
9. 用户列表搜索/状态/偏好筛选会影响列表和其顶部统计。使用分析的搜索会筛选对应用户群体，模型筛选会同时影响用量与趋势。
10. CSV 用户导出仅含当前页；分析摘要包含当前周期和筛选条件。文件使用 UTF-8 BOM 与标准 CSV 换行，并处理可能被表格软件当成公式的字段。

未接入人民币账单、用户创作内容与服务商服务器内部队列；不会根据目录素材数推测历史生成次数或费用。

## API 与存储边界

GET /api/users：参数 days（0/1/7/30/90）、page、size（最多 100）、search、status（enabled/disabled）、focus（text/image/video/audio/mixed/none）、sort（recent/registered/tokens/requests）、model。

GET /api/users/<userId>：参数 days、model、loginPage。返回白名单用户资料、当前周期统计、日趋势、模型分布、最近 50 条调用与 90 天登录记录（每页 20 条）。用户不存在返回 404，非法筛选返回 400。

接口仅存在于独立管理服务，并复用已有管理令牌鉴权。普通业务系统没有新增全局用户资料或 IP 查询接口。独立服务以只读 SQLite 事务查询，不加载原系统会执行写入初始化的数据库模块。

源系统仅增加两张日志相关表及注册/登录记录钩子；后台页面、查询 API 与自身数据目录均独立。升级前源文件备份位于 data/backups/userMonitor。

## 实际验证与限制

- 原系统服务端构建成功，新增表已在启动时创建。
- 后台脚本语法检查通过；真实数据库的空列表、周期/模型/偏好筛选正常；非法分页及筛选参数返回 400，未知或注入式用户 ID 返回 404。
- 业务系统未登录访问全局用量接口仍返回 401。
- 浏览器已验证用户搜索、偏好筛选、90 天周期、CSV 下载与编码。
- 源系统 typecheck 仍因原有缺失的 .hutch/devkit/api/config/ElectrobunConfig 生成类型而未通过。
- 当前没有普通注册用户和用户调用记录，因此尚未完成真实账号的注册/登录 IP 写入、用户详情有数据状态及非零消耗的端到端验收；没有为了展示效果创建模拟用户或伪造用量。


### IP 城市归属地
用户列表、用户资料和最近 90 天登录记录展示完整 IP、国家/省份/城市及可用的运营商。归属地由独立后台本地 ip2region 离线库解析，支持 IPv4/IPv6，不将用户 IP 发给第三方，不写入原业务库。内网、回环、共享与特殊地址单独标记；缺失、无匹配、城市库不可用均如实显示。归属地是当前库对网络出口的近似判断，不是 GPS，也不能可靠判断 VPN；历史 IP 使用当前库解析，不代表历史时刻的位置。
库位于 data/ipLocation/v4.xdb 和 v6.xdb，版本来源见 source.json；更新时从官方仓库下载兼容库并重启独立后台。部署时一并复制 vendor/ip2region 与 data/ipLocation。源码、库来源：https://github.com/lionsoul2014/ip2region ，许可见 vendor/ip2region/LICENSE.md。当前采用固定版本，不会自动联网更新。原业务服务上线需正确配置可信反向代理，才能取得真实客户端 IP；不要信任任意转发头。已验证当前真实注册用户的资料及登录历史接口；公网登录与反向代理真实 IP 仍需部署后联调验收。


### 全站成功视频输出累计
运营总览顶部横幅展示所有账号（包括管理员）的成功视频输出总数，按实际成功落盘的 result.length 入账，一段视频计 1 次，批量输出按段数累加。图片、文本、音频、失败、处理中、未知状态及仅人工核销的用量不计入。用量表 outputCount 与完成状态在同一事务写入，独立后台只读聚合，不在浏览器递增；刷新、重启或重复查询不会重复计数。统计不受日期、用户和模型筛选影响，页面每 5 秒自动刷新（弹窗或编辑筛选时沿用暂停刷新规则）。历史缺少输出数量的成功调用不推测补填，单独提示。视频片段输出次数不等于完整成片短剧部数。记录由原业务服务最小采集改动产生，界面、查询和服务仍保持独立。
